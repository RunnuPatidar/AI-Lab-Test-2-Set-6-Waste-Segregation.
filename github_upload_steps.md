# Upload to GitHub from a phone

1. Open github.com and sign in.
2. Tap **New repository**.
3. Repository name: `AI-Lab-Test-2-Set-6-Waste-Segregation`
4. Choose Public or Private as instructed by your teacher.
5. Add a README (or upload this project's README).
6. Create the repository.
7. Open the repository and use **Add file → Upload files**.
8. Upload `program.pl`, `README.md`, `test_cases.md`, `viva_questions.md`, `demo_script.md`, `video_link.txt`, and this file.
9. Commit the upload.
10. After recording and uploading the demo, edit `video_link.txt` and paste your video URL, then commit the change.

You may create the folder `output` on GitHub and upload screenshots of actual program execution there. Do not upload fabricated output screenshots.
